# Studylog

A simple study time tracker built with HTML, CSS, and JavaScript.

## What it does
- Log study sessions by subject and duration
- Delete sessions you no longer need
- See a breakdown of total time studied per subject
- Set a weekly study goal and track progress with a visual progress bar
- Export all sessions as a CSV file

## How to run it
1. Clone or download this repository
2. Open `index.html` in any web browser
3. No installation or setup needed — it runs entirely in the browser and saves data using localStorage

## Built with
- HTML
- CSS
- JavaScript (no frameworks)
